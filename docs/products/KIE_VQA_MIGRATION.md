# KIE / VQA 迁移使用说明

> 2026-10-25进展：RP14的A/P0–P5已实现按图KIE→新IoU→绑定消息VQA自动链路，见[使用说明](./KIE_VQA_PIPELINE.md)和[本轮报告](../../reports/kie_vqa_pipeline_implementation_20261024/REPORT.md)。区域链路为参考区域引导；B预测侧证据选择、G3真实在线和G4人工参考仍待验收。本文下方旧“后续开发”描述保留为当时范围。

2026-10-24。本轮把指定旧目录接入当前平台；没有新收费模型调用，也没有自动认证旧标注。

## 从哪里开始

- [审核台：KIE / VQA 标注](http://127.0.0.1:18431/review.html?section=benchmark)：查图片/字段，点击“核对原图与答案”。灰框是同图旧区域，橙框是当前参考，绿框是旧模型匹配。坐标默认锁定；点击橙框可编辑目标文本，解锁后可移动或拉角点。保存建立新标注版本，原图字节和旧版本保持。
- 可只保存评论，无须修改答案。评论和修订同步到质量过程；指定开发集后，生成台的“KIE / VQA 审核反馈”可读取意见，留出集意见不会进入生成反馈。
- 核对图片身份、案件组、用途和答案后，选择“人工通过”。勾选需要发布的任务，填写发布名称。开发集与留出集分开发布，同图字节或同案件组禁止跨用途。
- [评测台：KIE / VQA 任务](http://127.0.0.1:18431/evaluation.html?benchmark=1)：可以直接回放全部旧 IoU；新试跑要勾选任务，选择输入轨道、模型和调用预算。离线演练不计模型能力分。
- [操作台：本轮迁移](http://127.0.0.1:18431/evaluation.html?operations=1&kind=research.flow&record=kie-vqa-migration-20261024)：步骤、结果、修改意见、验证附件与相关记录。运行历史包含旧响应档案和新任务运行，均可跳转。

## 迁入了什么

1,132源文件逐一核验，原文件不改动。1,170张逻辑图片（1,168个字节哈希），其中1,088张源图，82张来自既有清单的候选，身份仍待核对。对应12,201条准备记录：11,002个VQA任务、1,170个KIE任务、29条旧审核意见。

旧工作流9份KIE汇总保留所有1,124条原始尝试，以及最终视图；另保留450条旧证据形式问答。错误、漏框、零IoU和低IoU不会被过滤。缺失usage、费用、原操作者和请求号保持未知。配置密钥不复制。6,333条旧IoU明细逐条一致，原阈值0.6下1,475条通过；这是旧区域关联结果，不是消息检测准确率。

## 输入与评分

KIE只看原图，不提供人工框或转录。图片VQA区分整图与明确指定区域。预测文本VQA只绑定同图、结构有效的KIE产物：既可用新结果编号，也可用历史响应列表中的prediction_ref（档案ID:行号）。上游失败记录为blocked_upstream，不用人工答案替补。人工转录辅助轨道尚无独立绑定材料，当前明确阻断。

新KIE输出要求完整消息字段、有限且不倒置的原图坐标。定位按一对一匹配，先最大匹配数再最大IoU，统计多检和漏检；阈值固定，不从待测批次自适应拟合。未建立人工消息级参考时只检查结构，不产生正式检测分。旧关联算法单独冻结，不与新检测成绩混合。

分类保留原文/归一化比较与分组混淆统计；金额必须明确Decimal值、币种和known/unknown，未知不按零；文件名不忽略大小写。身份别名、attitude及evidence_语义未定时阻断正式通过。开放分析在审核台按五项量表保存依据、发现和建议；该量表不认证法律正确性。新的自动模型裁判与专门法律认证仍须另行冻结评估协议，现有通用质量Prompt历史继续在审核台管理。

“开发参考评分”使用旧未复核答案，只作开发观察。“人工发布版本评分”只接受当前已审核发布的任务快照。离线重评追加评分版本，保留旧分数和原始响应；不会重新调用模型。服务失败、请求结果未知、明确弃答/未知、格式错误、取消、上游阻塞、无效参考和未计分分别统计。可以停止后续任务；失败/未知/未调用项只有显式重试才会新建运行，并保留原输入、模型和旧尝试。

## Prompt 与存储

答题Prompt在评测台保存Markdown版本、父版本和改动理由，可导出完整历史。质量裁判Prompt属于审核台，生成Prompt属于生成台。旧保存问句只归档，不自动用于新的纯视觉请求。输入预览会显示实际送入模型的字段，不含目标答案、审核评论、判决书或旧匹配消息。

沿用research.sqlite3的owner隔离records/jobs/idempotency/audit_events。benchmark.dataset/history/annotation/review/comment/quality/release/run/attempt/score与evaluation.task_prompt为新增记录类型。大清单和原图保存为受管文件，SQLite保存路径、SHA和绑定；业务写入与审计同事务。新标注和评分追加版本，发布冻结图片、标注、题目、输入、Prompt、模型和评分规则。草稿有本地缓存，任务审核还有服务器版本冲突保护。

## 尚需完成的实际工作

人工复核82个补图身份，建立KIE消息级目标和身份/标签字典，确认案件组与留出集；真实人类复核和法律认证不会由迁移脚本代签。旧VQA问句的原始构造器和论文评分器仍未找回，因此不能宣称旧论文成绩等价复现。真实模型试跑须另选明确任务和调用预算。本轮不增加V3独立认证数，也不改变V3发布门槛。
