# 长列表展示规范

适用：ScreenshotLegal 四个工作台与兼容控制台。继承 ../MASTER.md 的颜色、字体、图标和组件约束。

## 展示策略

- 全量接口返回的普通列表、历史、评论和结果：使用 components/collections 的 Paged。
- 已有服务端分页：保留原接口的 offset、next_offset、筛选条件和跨页选择，避免再次切分服务器页。
- 大型原生选择器：使用 SearchableSelect；超过 50 条时每页只挂载 50 个普通选项，当前选择可单独保留。原有外部检索的案件选择器沿用其搜索框。
- 图片和富文本卡片使用更小的初始页：图片时间线 8、审核页 4、原图 6、批次和编辑字段 10；普通集合默认 20。
- 短列表直接展示。长列表显示范围、总数、页码、上一页/下一页和每页数量，超过 5 页提供直接跳页。
- 表格分页/检索放在横向滚动区外。仅表格内容横向滚动，分页操作始终保持可见。
- 不增加无限滚动；记录总数明确，任意一页均可到达。

## 状态与数据完整性

- 只切分展示，不切分提交载荷。跨页发布勾选、模型勾选和候选选择继续由上层完整数组持有。
- 已选记录在异步加载后定位至所在页；用户手动翻页后，轮询更新不能将其强行拉回。
- 筛选变化和清除搜索回到第一页。记录减少时钳制页码，自定义每页数量后也不能失去剩余记录的入口。
- 按数组下标编辑的消息与题目使用真实偏移量，不能把第二页的第一个项目当作全列表第一项。
- 评论修订草稿由评论 ID 在父级保留；翻页回来仍可恢复正文、处理依据和适用范围。
- 不用 slice(0, N) 静默截断。可关联质量反馈已移除原来的前 100 条限制。
- 来源坐标框、图形覆盖层、固定导航和固定指标分类保持其完整语义；不对几何覆盖层分页。

## 可访问性与响应式

- 分页按钮必须 type=button，不能触发所在业务表单提交。
- 使用原生 select、input、button；所有控件保留可见标签、键盘焦点和禁用状态。
- 计数使用一个上下文完整的 polite live region。零匹配时提供清除搜索。
- 分页区使用带名称的 group，保持现有工作台导航 landmark 的意义。
- 使用稳定记录 ID 作为 key。避免对已保存消息的坐标、顺序或时间作推断。
- 375px 窄屏下控件可换行，页面本身不能横向溢出；宽表格局部滚动。

## 实现边界

本轮采用前端分页限制 DOM 挂载数量，未改动后端响应或权限。它减少已挂载行、图片和原生 option 数量；全量接口的网络传输量和浏览器数据数组规模仍由原接口决定。后续若数据增长到全量接口本身成为瓶颈，应再实施服务端分页，而非宣称当前已降低网络开销。
