## 三种运行身份

| 模式 | 允许结论 |
| --- | --- |
| legacy_replay | 对保存响应按当时规则重算、核对迁移一致性；不是新模型调用 |
| development_reference | 对旧参考标注做明确标注的开发诊断；未复核目标、缺图和坏题数量同时报告 |
| official_reviewed | 使用已审核目标、固定划分、输入/输出与评分协议、模型快照及预算进行正式计分 |

旧论文Hit Rate / Similarity / Length定义和实现未在指定目录中找到，不能自行发明公式后称复现成功。旧450条evidence模式复合输出也不能替代6,333消息题的完整回答与评分历史。

## 输入轨道

1. KIE整图：仅原图和抽取规则，不输入金标框、人工转录、答案或审核意见。
2. 图片VQA：问题、明确字段定义、原图；只有定位区域协议允许给参考ROI。整图与ROI、单图与多图独立报告。
3. 预测文本辅助VQA：冻结实际KIE预测及哈希；是否同时给图由单独混合协议规定。上游失败保留blocked_upstream，不以人工文本补齐。
4. 人工转录辅助：只作诊断轨道，不能并入纯图片或KIE预测辅助成绩。

当前evaluation_input会按message_ids筛页面。实施新适配时必须显式选择full_document/declared_pages/declared_roi，不能借金标支持集隐式缩小模型所见范围。

## 旧IoU与关联复现

rectTool的x,y,width,height转[x,y,x+w,y+h]；message_bbox转[min_x,min_y,max_x,max_y]。旧公式为：

`IoU = intersection / (area_a + area_b - intersection + 1e-9)`

无交集或非正面积时返回0。每个属性框在同图预测消息中独立选择最大IoU，严格更大才替换，因此相等时保留遍历先项；允许多属性复用同一消息。保存问句阈值0.60，按>=判断；6,333行中1,475行通过，4,858行不通过。no_message与“有消息但零交集”分别保存。

这一分数只说明属性区域与抽取消息的几何关联，不是完整检测准确率。额外预测框未被计为FP，多个属性可能属于一个物理框。legacy --one2one删除行及final_bbox仅保留有框的行为必须作为历史诊断说明，不能用它们筛除新版评测分母。自适应阈值会随被测结果改变，不能在正式测试集拟合阈值。

## 新KIE评分

先验证JSON/必需字段/坐标有限性/正面积/尺寸和图像方向。只存在某个数值框不算抽取成功。保存原始值和错误，不静默丢弃坏框。

检测单元为人工确认的物理区域与语义类型。消息框、头像框、金额片段不能混作同一检测类别。现存4,209个属性区域的类型未充分确认，450条模型结构化输出也不是人工消息框金标，因此正式检测P/R暂不可用。

候选新规则：同图同类型、IoU>=固定阈值构造边，优先最大匹配数量，再最大总IoU，稳定ID打破并列；未匹配参考框为FN，未匹配预测框为FP。主阈值建议0.60用于延续旧关联诊断，0.50/0.75可附报；这些是项目草案选择，须在开发集校准后冻结。

报告precision、recall、F1、匹配框平均IoU、GT覆盖与FP/FN。字段报告端到端正确率（漏检字段仍在分母）和仅匹配字段正确率，两者分别展示。文本保留原始精确匹配与字符错误率；身份、时间、金额、文件名独立出分。image/transfer/file等字段必须保留，不因旧匹配视图忽略它们而从任务删除。

## VQA分项评分

| 答案类型 | 协议 |
| --- | --- |
| 分类 | 冻结标签字典；准确率、逐类P/R/F1、macro-F1和混淆矩阵。evidence保持规范截图证据形式含义，不自动变成法院采信判断 |
| 身份 | 账号内ID、可见昵称、真实身份分开；先有审核过的别名表。引用ID无法解释时标注参考不可评分，不把unknown视为必然识别失败 |
| 金额 | 原文+Decimal字符串+币种+answer_status；未知值为null/unknown，不是0；歧义参考先复核 |
| 文件名 | 明确Unicode、大小写、扩展名策略，原始与归一化匹配分开 |
| 开放答案 | 可见事实正确性、问题相关性、证据支持、额外假设、适当保留判断分别评价；法律维度须明确范围和规则来源并经相应复核 |
| 多选集合（后续范围） | 类型为集合，按冻结别名与集合匹配/逐标签指标评价；不能直接比较列表字符串顺序。本目录不含完整案件多图选择题集 |

文本诊断默认NFC与外侧空白处理，原始精确匹配另存。不得为了提高命中率全局删标点、改头像ID、把evidence_合并进evidence或把未知金额转0。标注值todo/photo等含义未定时保留旧枚举，正式语义评分禁用。

开放题的字符串精确匹配或字词重合只作诊断，不能命名为法律正确率。若增加模型裁判，单独冻结裁判模型/Prompt/量表、记录理由和费用，并允许人工复核；它不认证人工金标。

## 分母与失败状态

每轮同时报告planned、attempted、response_received、valid_output、service_failed、unknown、cancelled、blocked_upstream、invalid_reference、scorable。每个原任务都有最终状态，低IoU、无框、失败和格式错误不能从记录消失。

内容质量指标仅对已定义的可评分目标与响应状态计算；模型格式错误/拒答按预先冻结规则记入，不能只挑成功解析回答。服务失败和未知调用另报服务覆盖与完整计划分母，不将其直接解释为法律能力错误。未审核/不成立的金标标不可评分并显示数量，不补0分。29条bug_report作为审核意见显式保留，默认模型题分母排除有单独声明。

仅给出有效回答上的指标时必须同时显示原计划分母和覆盖率。旧计划总调用数、费用、usage缺失无法确认时保持unknown，不能把聚合JSON行数当作实际付费调用数。

## 落库与重评

冻结源文件/图片/标注/输入/Prompt/输出schema/评分器及参数/模型版本；串联任务绑定上游预测。原始回答先保存，解析、匹配、评分分别记录产物哈希、错误和耗时。

同一响应换金标、量表或归一化规则时新增Score版本，保留旧分数和修改意见；不自动重跑模型。进入正式发布与计分前需通过资产身份、参考目标、任务范围、划分、评分器回归及当前人工审核绑定门槛。迁入批次当前正式就绪任务数为0；基础代码已交付，正式数据/协议与在线自动链路仍待验收。后续分层指标、ScoreSet与冻结字典要求见[RP14验收策略](KIE_VQA_PIPELINE_ACCEPTANCE.md)。
