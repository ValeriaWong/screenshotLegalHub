# 审核可靠性与操作审计

更新：2026-10-24（Asia/Singapore）。实现及验证见[本轮交付报告](../../product_v1/reports/reliability-audit-2026-10-24/REPORT.md)，任务状态见[开发计划](../ai_docs_center/RESEARCH_PRODUCTS_PLAN.md)。

## 保存与审核

- 编辑文本/说明或坐标后保存，只确认点击时的快照。保存期间继续输入的内容保留为下一轮草稿；刷新可恢复，不会把未提交部分标为已保存。
- Prompt切换名称时加载该名称草稿或已保存版本；“基于此版本继续迭代”固定参考版本及CAS基线，并保留Markdown、意见和反馈依据。
- 坐标仍默认锁定，取消锁定后才能拖拽/缩放；正文最低16px，合成框不能重叠遮挡。文本超出框时保留文字和旧图，扩大框后保存恢复。
- 真实原图、转录标注视图、合成图有明确身份。原件无转录时仍使用原图进入图片评测，不以标题或来源占位图替代。
- 历史导入若仍显示旧派生图，可点击“接入导入原图及坐标为新版本”。系统校验来源/哈希和转录，生成新revision，保留样本ID、旧图与历史；已改转录不能冒用旧原图。

## 通过、金标与发布

1. 图片就绪后，在质量区域选择“文本与图片”并勾选“已核对上方当前图片”。确认记录绑定明确manifest和内容版本；仅文本或仅图片通过不能单独发布。
2. 题目勾选金标是申请。保存后，还需在当前质量审核中勾选“同时确认本版本勾选题目的答案与证据为金标”。题目、答案、任务或证据变化会使旧确认失效。
3. 新发布使用research.v2契约，固定revision、实际视觉资产、人工审核和金标认证。无金标题仍可保留并显示未评分。历史未绑定release可查看，不能直接创建新正式评测。
4. 旧图片若没有新契约有效性检查，在下方任务中“校验并修复产物”后重新审核；不能直接沿用历史绿色通过状态。

绑定说明的是明确确认对象，不代替独立专业审查或证明审核者实际认真看过每一处内容。

## 评论与质量比较

评论可以独立保存。默认仅适用于该版本；勾选“适用于同源后续版本”表示长期规则。历史评论不覆盖，可修订或记录待处理、采纳、解决、不采纳、撤回及原因。修订/处理同步追加到质量历史。

生成台按条选择反馈并冻结快照。生成候选页展示本批实际采用的意见，可在人工核对后记录解决结果，验证对象固定为候选revision和内容摘要。已解决/撤回/不采纳意见不再作为默认有效反馈；批次已经冻结的旧意见保留。

质量模型区可选仅文本、图片与来源/题目、文本与图片。视觉任务发送实际绑定图片，需要支持图片的模型。质量比较按评估协议、初稿/修订阶段拆分，显示覆盖率和失败/取消/未知尝试；只做分组观察，不自动认定生成Prompt因果改进。

## 操作审计页面

三台导航的“操作审计”可进入；用户工作台也有入口。样本、Prompt、批次、发布和评测运行提供各自操作历史入口。

页面支持产品、动作、结果、对象/关联ID、操作者及时间范围过滤；概览统计整个筛选集合。可切换分页表格和时间线，打开差异抽屉，查看父事件、关联样本/release/run/job、请求与结果引用，并导出筛选结果JSON。事件按实际发生时间及稳定序号排序，时间显示为新加坡时间，日分布按UTC归组。

审计默认只展示当前用户有权查看的记录，管理员不会因角色名自动看到所有账户事件。模型密钥/认证头不记录，原始模型响应通过授权资源引用查看，不整份复制到审计表。

## 存储和迁移

研究库位于product_v1/data/research/research.sqlite3：records、jobs、idempotency保持，新增audit_events、schema_migrations。正式业务变更与成功事件同事务；拒绝/冲突在回滚后记录。审计事件为追加式记录，但不宣称本地SQLite文件具有不可篡改认证。

用户工作台与模型配置在各自案件库事务中写run_events操作事件，经公开接口幂等投影到统一审计页；不是跨库分布式事务。旧专项egress_audit/skill_runs仍按原方式保留，不被本轮自动转换成虚构历史操作。

首次升级只为已有样本/发布/批次/运行建立migration_snapshot，原操作者和时间未知；不改写原业务记录。数据库备份在product_v1/data/backups，具体路径记录于交付报告。本轮本机仍2687案，73条研究业务记录原字节摘要保持。

草稿冲突有拒绝事件，普通键入、鼠标移动和自动草稿保存不逐条记审计。开发代码/文档修改仍由仓库报告管理，不冒充业务操作。
