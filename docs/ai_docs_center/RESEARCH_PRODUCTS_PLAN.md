## 审核与发布的目标契约（已实现）

1. 视觉对象明确角色：original（原件）、transcription_overlay（转录标注视图）、synthetic_render（合成渲染）。每个对象固定 asset_id、SHA256、尺寸、坐标系；手动 bbox 引用具体资产/manifest。原始图片字节不可覆盖，文字校正产生独立派生视图。
2. 人工审核记录绑定 sample_id、revision、content_hash、review_scope、所审资产集合/manifest_hash。文本与图片审核范围分开。图片未就绪不能确认图片通过；API 也须校验，不只禁用按钮。绑定能记录明确确认的对象，不能证明审核者实际认真看过内容。
3. 金标认证绑定 question、answer、task_type、message_ids/证据及相关来源/内容摘要；任一依赖变化使对应认证失效，保留旧认证。后端执行失效规则，前端解释需复核的原因；仅 gold=true 不再代表足够的发布依据。
4. release 固定选定 revision、实际视觉资产、有效审核记录、有效金标认证及参数摘要。标为金标的题必须有当前有效认证；无金标题仍可按明确范围纳入并保持 unscored。评测直接消费该快照，不能偷偷回退 title/source 占位图或跟随 latest。
5. 合成渲染的“文件完成”与“视觉有效”分开。完全遮挡/正文缺失属于阻断项；可读性阈值与允许重叠规则需版本化并在 UI 可见。当前固定框缩到 8px 的隐式策略需改为明确失败或用户知情处理。
6. 历史记录新增 legacy_unbound/needs_reconfirmation 等兼容状态；原有发布/历史导出保留，不伪造审核时间、操作者或资产绑定。新的正式发布必须重新满足契约；读取旧 release 时显式提示旧契约。

## SQLite 操作审计设计（已实现）

继续使用单体与现有SQLite。records/jobs/idempotency保留，已新增audit_events/schema_migrations；DDL与一次性迁移位于research/audit.py和store.py，正式业务事件同事务落库。

| 字段组 | 已保存内容 |
| --- | --- |
| 身份与检索列 | id、schema_version、owner、actor_id、actor_type（user/worker/system）、product、action、object_type/object_id、outcome、occurred_at |
| 串联与幂等 | request_id、correlation_id、parent_event_id、event_key；UNIQUE(owner,event_key) 防重复事件 |
| 上下文 JSON | sample_id/revision、content_hash、manifest/asset_hash、gold/review/release/batch/run/job 的关联 ID，按事件类型选择 |
| 变更与依据 | changed_fields、脱敏 before/after 或 patch、reason、result_ref（结果/错误记录引用） |

索引优先覆盖 (owner,occurred_at,id)、(owner,object_type,object_id,occurred_at,id)、(owner,product,action,occurred_at,id)。时间线按稳定时间及 ID 游标分页，不把全量历史送前端后再筛选。事件摘要不复制大段原文、整张图片或所有模型响应，详情通过授权资源引用读取。

入库规则：

- 事件追加保存，不提供常规修改/删除接口；应用层和数据库约束阻止误覆盖。SQLite 本地文件仍可被有写权限的人改动，不能宣称已实现防篡改认证。
- 成功变更与对应 success 事件使用同一事务；事件写入失败则业务写入回滚，不能出现“已修改但无审计”。SQLite 文件/图片原子写入和数据库事件的边界需保留准备/成功/失败状态，不宣称跨文件系统分布式事务。
- CAS/权限/校验拒绝及执行失败，在业务事务回滚后按权限与安全边界另写 rejected/failed；模型调用无法确认的结果写 unknown，不能自动改成成功。审计失败不覆盖原始业务错误，需留下明确运维错误。
- 事件 event_key 绑定一次逻辑操作与结果，重复请求不重复追加 success；重试是新操作，串联原事件/任务。任务里程碑与恢复保留，心跳和每次鼠标移动不逐条写审计。
- 默认记录正式样本/坐标保存、评论及处理、Prompt 版本、质量评估提交/结果、金标确认/失效、发布、批次/评测创建、取消/重试/失败、导入/导出。草稿记录必要冲突拒绝，普通自动保存/恢复不逐条写审计，不记录每次键入。
- 已覆盖研究三台/导入及模型配置、用户工作台编辑；后两者在主库run_events中写事务操作事件，经Workspace公开接口幂等投影。egress_audit/skill_runs专项历史继续保留，未伪造转换。
