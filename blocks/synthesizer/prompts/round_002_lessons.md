# 第二轮实际写作得到的修订规则

这些规则来自两案写作与历史意见对照，尚未证明在全池泛化；不要把这一页当成已经实跑的模型 prompt。

1. 先写来源约束：已认定的事实、逐字消息、附件存在、单方陈述、争议和缺口。遇到争议不能选择对一方更有利的版本并伪装成原话。
2. 先决定会话对象的实际任务。会计处理合同文件和付款；项目经理处理到货和参数。家人有共同背景，用联络、拖延、追问表达意图，不反复念案件摘要。
3. 原话必须保留字符、标点和原有错误。不能为了自然感附加表情、整理用词或拆成额外发送动作。
4. PDF 用文件卡表示。仅有文件名称不能推定内容在截图可见。按来源重建条目图时，单独标明原件未取得和新创作的裁切/发图动作；题目只问实际展示的信息。
5. “没有回复”不写成聊天气泡或系统提示。没有截图可见的承诺就不能制造承诺，留给证据理解任务判断边界。
6. 衔接只补交流节奏，不补新的决定性事实：放弃权益、收到文书、确认变更、承认造假、款项性质或时间先后均不能靠随机对白补齐。
7. 分钟可以模拟，但日期必须由来源约束。人物当时还不知道的病情、资产、文书或判决结论不得提前出现。
8. 自审逐句给出错误 ID、修改前后和依据，不用一个自然感总分代替修改。版本、原始反馈和 source span 均保留。
9. 先看实际固定尺寸 PNG：完整性、英文换行、日期、群内说话人、附件可读性和分页重复。消息增加、图片增加不等于难度增加。
10. 题目单独做图片盲评、必要证据遮挡和模型实跑。源判决能回答不等于截图能回答；“提议”“执行”“知悉”“收到文书”不能混为一谈。
