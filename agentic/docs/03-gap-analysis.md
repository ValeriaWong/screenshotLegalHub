# 缺口与可补全性

| 缺口 | 本次代码/Prompt/模型补齐 | 无法自动补齐的边界 |
| --- | --- | --- |
| 包只有抽象接口/检索 Adapter | 五个真实阶段 Skill、五个确定性 Tool、可选 stage_reasoning Tool、自包含输入与报告 | 不承诺现有旧线全部业务功能等价迁移 |
| 没有 Planning 或阶段 Prompt | 代码 DAG + 可增加白名单重点的模型规划；每阶段版本化 Prompt | 模型不能改写权限、跳过 Gate 或生成任意执行代码 |
| 未知时间与重复金额 | 时间精度校验、Decimal 金额提及、不累计为真实流水 | 缺失日期、交易是否同一、支付是否实际发生需证据 |
| 事实/推断混淆 | 原文账本与候选判断分栏；模型观察必须是原文摘录；引用逐字验证 | 引用匹配不证明实质支持或现实真实性 |
| 竞争性解释与遗漏前提 | 词面检查 + 模型阶段分析/候选缺口，所有来源可跳转 | 模型效果本次未线上验证，完整语义与专业判断不由规则认证 |
| 结论过度确定 | determination 固定为 insufficient；证据/人工关键缺口不能被推断关闭 | 无完整材料与专业复核，不输出确定法律认定 |
| 模型可靠性与费用 | Responses 调用、严格结构、超时、有限重试、额度预留/结算 | 价格由部署方配置；缺失 usage 保守预留，不保证等于最终账单 |
| 输出仅 JSON | 四个导航页签、来源弹窗、筛选、打印/JSON 下载 | 当前工具无浏览器，未完成真实截图检查；DOM 测试已覆盖事件逻辑 |

对 docs/ai_docs_center 的 G01–G18：本包可改进来源可追溯、未知前提保护、模型预算、分阶段输出和结论边界。来源许可、校准与干预包、两位独立复核、充分性/最小性认证、留出评测、论文与发布验收等仍是外部研究/专业任务。不得把代码测试 PASS 当成这些 Gap 已关闭。

当前范围不含 OCR、原始图片/文件认证、法律数据库、长期 Memory、多 worker 队列、原生 Responses 推理服务器、Dify 云端部署。模型调用通过配置接入；本次用户明确选择“先交付独立包和本地报告，保留模型接入配置”。
